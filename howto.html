Bien utiliser Ocean Infinity

Clique une étape. À droite : la démo (vidéo ou image) + l’explication simple.

Étape 1

Créer / ouvrir la “Plongée du jour”

Tu poses les constantes (DP, bateau, site). C’est la base de tout le reste.

  • Renseigne DP / bateau / sécurité surface.
  • Renseigne site + coordonnées si besoin.
  • Vérifie avant de passer aux plongeurs.

Astuce : si une vidéo ne se charge pas (offline), commence par vérifier que les fichiers existent bien dans /assets/howto/.
