Bien utiliser Ocean Infinity

Ce guide décrit le workflow recommandé “jour J” (DP / bateau / groupes / PDF).

Workflow standard

  1. Créer / ouvrir la “Plongée du jour”
  2. Sélectionner les plongeurs présents
  3. Affecter les unités (B1…BN)
  4. Constituer les groupes (Autonome / Encadré / Formation)
  5. Vérifier responsables & encadrants
  6. Exporter le PDF officiel

Bonnes pratiques terrain

  • Stabiliser la liste “présents à bord” avant la constitution des groupes.
  • Une unité par plongeur quand il y a plusieurs bateaux.
  • Exporter PDF uniquement une fois la structure validée.
